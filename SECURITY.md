# Security policy

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button on this repository's Security tab, not in public issues.

Include what you found, how to reproduce it and what an attacker could do with it. You should get a reply within a week.

Triagent handles source-code excerpts, GitHub credentials and LLM API keys, so reports about tenant isolation, secret handling, authentication and the review runner are especially welcome.
